# Формат импорта Excel (ПСДЦ / КС-6)

Принимаются только `.xlsx`. Приём — через единый guard
(`lib/uploads/file-guard.ts`): сигнатура `PK\x03\x04` по накопленным ≥8 байтам,
инспекция zip-оглавления (обязателен `xl/workbook.xml`, запрещён
`vbaProject.bin` — xlsm под маской, лимиты записей и заявленного размера
распаковки), лимит файла 25 МБ (`UPLOAD_MAX_BYTES`). Отвергнутый файл не
попадает в хранилище ни байтом. Разбор — только в parse-child (см. architecture.md).

## Лист «ПСДЦ»

- Берётся **видимый** лист с именем `ПСДЦ`; иначе ошибка с перечнем видимых листов.
- Строка заголовков ищется в первых 30 строках по одновременному наличию
  «№ п/п», «Вид», «Наименование работ…». Колонки сопоставляются по текстам
  заголовков (Код КВР, Статья бюджета, Характеристика, Кол-во, Ед.изм.,
  Цена за ед., Ст-ть материала/работ на ед., Стоимость).
- Строка цифровой нумерации граф под шапкой пропускается; данные — до строки «Итого…».
- Классификация строки:
  - `Вид = КВР` → агрегирующая строка работ;
  - `Вид = Номенклатура` → детальная строка (привязывается к последнему КВР);
  - иначе, если заполнена **Ед. изм.** → номенклатура (предупреждение);
  - иначе → раздел. Уровень: есть сумма в «Стоимость» → 1-й, нет → 2-й
    (вложенный в последний раздел 1-го уровня); не-жирные строки без сумм
    помечаются предупреждением «возможно, аннотация».
- «Итого…» и «НДС 20%» читаются как контрольные числа файла.

## Лист «КС-6»

- Табличная шапка — строка с «№ п/п» + «Код КВР» + «Наименование работ»;
  подзаголовки граф — строкой ниже; колонка «Вид» — из цифровой строки под ними.
- Договорные графы по подзаголовкам: Ед.изм., Кол-во един., Цена за ед.,
  Стоимость материала/работ на ед., Всего.
- Пара «Выполнение с нач. ст-ва» — контрольная (не импортируется как период).
- Помесячные пары «Кол-во/Стоимость» сканируются правее неё до колонки
  с пометкой «Остаток»/«Выполнено» в строке подписей. Метаданные пары:
  - подпись (строка над шапкой): `КС-2 №N`, период `дд.мм.гг(гг)-дд.мм.гг(гг)`
    или дата `от дд.мм.гггг`;
  - месяц — из строки дат (ещё выше).
  - Пары без подписи/даты и без значений пропускаются; пара со значениями, но
    без номера требует ручного ввода номера в предпросмотре (пример: текущий
    «КС-2 в работе» — первая пара без подписи).
- Строки классифицируются как в ПСДЦ. Номенклатура без кода КВР привязывается
  к предыдущему КВР. Итоги разделов/«Остаток»/«Выполнено ВСЕГО» из файла
  НЕ импортируются — портал пересчитывает их сам.

## Агрегирующие «номенклатуры»

Строка с `Вид = Номенклатура`, чей «Всего» равен (±0,05 ₽) сумме ≥2 следующих
подряд номенклатур того же раздела, распознаётся как агрегат: переводится в КВР,
строки ниже привязываются к ней (пример из эталона: «Прижимная стена» = сумма
7 строк «Прижимная стенка …»). Без этого суммы задваиваются.

## Diff и применение

УИД строк в файлах пуст, поэтому сопоставление с существующей структурой:
ключ (вид, код КВР, нормализованное имя, ед. изм.) + порядковый номер дубля.
Статусы: `новая` (в непустом договоре требует выбора ДС — строка получит метку
и подсветку), `совпадает`, `изменена` (применяется только по флагу
`applyChanged`), `нет в файле` (ничего не удаляется — только предупреждение).

История КС-2 (kind=ks6, `importHistory`): документы матчатся по номеру;
существующие не трогаются без `overwriteKs2` (только админ). Импортированные
КС-2 создаются утверждёнными (история — свершившийся факт), суммы строк — как
в файле. Незаполненные периоды подставляются из месяца колонки (границы месяца)
и редактируются в предпросмотре.

## Контрольные суммы и известные неувязки эталона

Предпросмотр сверяет: Σ номенклатур ↔ «Итого» файла, Σ помесячных ↔ контрольную
колонку «Выполнение с нач. ст-ва». В эталонном файле есть внутренние неувязки
самого Excel (±копейки: «Итого» файла считается по КВР-строкам и отличается от
Σ номенклатур на 0,05 ₽; строка «Итого» помесячных колонок расходится с Σ ячеек
на 1,31 ₽). Источник истины в портале — суммы номенклатур; расхождения
показываются предупреждениями и не блокируют применение.
