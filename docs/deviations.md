# Отступления от корпстандарта v3.1 и skill office-documents

Фиксация осознанных отступлений базовой реализации (этап 1). Принято при
проектировании портала «КС», 2026-08-20, по согласованию с заказчиком
(владелец продукта — постановка задачи в этом репозитории).

## 1. Ant Design 6 вместо Ant Design 5

Корпстандарт §6 фиксирует AntD 5. Заказчик явно потребовал AntD 6
(«дизайн лаконичный, современный; фреймворк ant design 6»).
Следствия: cssVar-темизация по умолчанию, React ≥ 18, только `items`-API,
`App.useApp()` для message/notification/modal, ProComponents и другие
v5-обвязки не используются. Риск совместимости закрыт смоук-тестом
virtual-таблицы + fixed columns + column groups в реальном браузере.

## 2. exceljs для разбора недоверенных файлов

Skill office-documents закрепляет Apache POI для разбора; exceljs одобрен
только для генерации. Этап 1 сознательно остаётся Node-only: разбор выполняет
exceljs, но в **одноразовом дочернем процессе без секретов** (чистый env,
без БД и сети), с жёстким wall-clock таймаутом (SIGKILL), лимитом stdout и
лимитами контейнера worker в production-compose. Контейнер файла инспектируется
до разбора (сигнатура, zip-оглавление, запрет vbaProject.bin, лимит заявленной
распаковки); враждебные фикстуры (zip-бомба, xlsm под маской, битый архив)
покрыты тестами `src/tests/file-guard.test.ts`. Пересмотр на этапе 2 вместе с
общим контуром конвертации `/opt/infra/docs`.

## 3. Локальное файловое хранилище вместо S3 + presigned URL

Корпстандарт §15 требует S3-совместимое хранилище и presigned-загрузку.
На этапе 1 файлы импорта (единственные файлы системы) хранятся в volume
(`.data/uploads`) за интерфейсом `lib/storage/storage.ts`; ключи генерирует
backend, пользовательский ввод в путь не попадает, выдача — только
`Content-Disposition: attachment` + `nosniff`. Переход на S3 — замена
реализации интерфейса без изменения бизнес-кода.

## 4. Без Keycloak/AD, SES, Sentry, managed-мониторинга

По постановке задачи это этап 2. Реализован standalone auth mode (§13
корпстандарта: rotation, reuse detection, hash refresh-токенов в БД),
health-эндпоинты, pino JSON-логи с redaction, audit_log, production startup
checks. Email-уведомлений нет (активация пользователей — вручную админом).

## 5. Dev-БД: embedded-postgres вместо Docker

На машинах разработчиков без Docker dev-БД поднимается пакетом
embedded-postgres (реальный PostgreSQL 17, UTF-8, локальный порт 5439,
запуск через pg_ctl из-за запрета PostgreSQL работать под админским токеном
Windows). Вариант с Docker сохранён (`deploy/docker-compose.dev.yml`).
Production — только Yandex Managed PostgreSQL (§7).

## 6. Экспорт КС-2 — упрощённая форма

Точная форма по ОКУД 0322005 не является целью этапа 1: выгружается акт с
реквизитами, строками выполнения за период, итогом и НДС. Точная форма —
отдельная задача этапа 2.
