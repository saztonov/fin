# Правила проекта «Портал КС»

## Коммиты

Заголовок коммита — осмысленная строка на русском языке. **Коммитов с заголовком `@`
(и вообще начинающихся с `@`) быть не должно.**

Откуда берётся `@`: основная оболочка здесь PowerShell, а многострочные сообщения
часто пишутся через Bash. PowerShell-синтаксис here-string `@'…'@` в Bash не
работает — символ `@` уходит в сообщение буквально и становится заголовком коммита,
а осмысленный текст съезжает в тело.

Как писать многострочное сообщение:

- **Bash** — `git commit -F -` с heredoc:

  ```bash
  git commit -F - <<'EOF'
  Заголовок коммита

  Тело: что и почему изменилось.
  EOF
  ```

- **PowerShell** — `git commit -m @'…'@`, закрывающий `'@` строго с нулевой колонки.

После коммита сверять результат: `git log -1 --format=%s` — заголовок должен читаться
как нормальная фраза. Если в заголовок попал мусор, поправить `git commit --amend`
до пуша (после пуша — только с согласия владельца репозитория).
